# Fonts

The site uses its own copies of these fonts, so it loads nothing from other sites.

| File | Font | Used for | Licence |
|---|---|---|---|
| `andika-*.woff` | Andika 6.101 (SIL International) | Interface, menus, buttons and headings | SIL OFL 1.1 |
| `patrickhand-regular.woff` | Patrick Hand 1.003 (Patrick Wagesreiter) | Definitions, key ideas, quiz text | SIL OFL 1.1 |
| `specialelite-regular.woff` | Special Elite 1.001 (Astigmatic) | Equations, numbers, calculator results, stamps | Apache 2.0 |
| `permanentmarker-regular.woff` | Permanent Marker 1.001 (Font Diner) | Page titles, big letters, numbers | Apache 2.0 |
| `kalam-*.woff` | Kalam 2.001 (Indian Type Foundry) | Handwritten notes and labels | SIL OFL 1.1 |

The licence texts are in [licenses/](licenses/). The files come from the Google Fonts repository (`github.com/google/fonts`) and were repackaged from TTF to WOFF with fontTools. WOFF only compresses the font tables, so the glyphs, metrics and names are unchanged; nothing was subset or edited.
